# Project LOOP — AI Customer Feedback Intelligence Platform

Zidio Development Internship Project — Web Development Track

## What it does
LOOP ingests multi-channel customer feedback (support tickets, reviews, surveys, sales notes),
uses AI to classify and cluster it into themes, detects trends, and answers plain-English
questions grounded in the actual feedback data.

## Tech stack
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: MongoDB (Mongoose)
- AI: Anthropic Claude API
